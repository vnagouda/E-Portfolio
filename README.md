## 🛰️ MISSION OVERVIEW

A high-performance, minimalist E-Portfolio designed for visual impact and technical clarity. Built with **React + Vite**, this system serves as a digital registry of experimental projects, core systems, and professional contact protocols.

### 🧪 CORE SYSTEMS
- **Dynamic Background Control:** Procedural animation layer for immersive UX.
- **System Registry:** Centralized directory for project categorization and discovery.
- **Responsive Terminal:** Seamless transitions across all device viewports.
- **Contact Protocol:** Integrated submission pipeline for professional inquiries.

## 🎮 LOCAL INITIALIZATION

To clone and run this system locally:

```bash
# 1. Clone Registry
git clone https://github.com/vnagouda/E-Portfolio.git

# 2. Access Core
cd E-Portfolio

# 3. Inject Dependencies
npm install

# 4. Initialize Dev Environment
npm run dev
```

## 📡 DEPLOYMENT PROTOCOL

```bash
# Deploy to Production
npm run deploy
```
